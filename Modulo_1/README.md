## Descripción
Eate proyecto es una calculadora del indice de Masa Corpolar en paython.
El programa solicuta al usuario su nombre, apellidos, edad, peso y estatura.
Después muestra los datos ingresados y calcula el imc.

### Como ejecutar el programa 
1. abrir el programa de Python
2. Ejecutar el programa
3. ingresar los datos que se piden 
4. si algún dato es incorrecto o se deja vació, el programa marcara error y solicitará ingresarlo nuevamente.
5. Al final se mostraran todos los datos y se mostrara el resultado del IMC y el IMC con dos puntos decimales.
